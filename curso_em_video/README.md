# Curso em Vídeo - Python

Esta pasta reúne os exercícios, desafios e pequenos projetos desenvolvidos durante o curso de **Python** do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo é consolidar os fundamentos da linguagem por meio da resolução prática de exercícios, acompanhando a evolução do conteúdo apresentado ao longo do curso.

### 🌍 Mundo 1
Introdução à programação com Python.

**Principais tópicos:**
- Variáveis
- Tipos de dados
- Entrada e saída de dados
- Operadores
- Módulos
- Condições (`if`, `elif`, `else`)

---

### 🌍 Mundo 2
Estruturas de repetição e lógica de programação.

**Principais tópicos:**
- Laços `for`
- Laços `while`
- Condições aninhadas
- Controle de fluxo
- Exercícios de lógica

---

### 🌍 Mundo 3
Estruturas de dados e recursos mais avançados da linguagem.

**Principais tópicos:**
- Tuplas
- Listas
- Dicionários
- Funções
- Modularização
- Tratamento de erros
