# freeCodeCamp - Python Labs

Esta pasta reúne os laboratórios e desafios desenvolvidos durante o curso de **Python** do **freeCodeCamp**.

O objetivo é registrar minha evolução na linguagem, praticando conceitos fundamentais de programação por meio de desafios práticos e incrementais.

Cada laboratório possui sua própria pasta contendo o código-fonte e um README explicando o problema proposto, a solução desenvolvida e os principais conceitos praticados.

---

## 📚 Conteúdo

| Laboratório | Conceitos |
|-------------|-----------|
| Caesar Cipher | Strings, funções, validações, `str.maketrans()`, criptografia |
| RPG Character Builder | Funções, condicionais, validação de dados, formatação de strings |
| Pin Extractor | Strings, listas, loops, `split()`, `enumerate()`, `append()`, tratamento de índices |
| *(Em breve...)* | Novos laboratórios serão adicionados conforme avanço no curso. |

---

## 🛠️ Tecnologias

- Python 3

## 📖 Conceitos praticados

Ao longo destes laboratórios venho praticando:

- Funções
- Parâmetros e retorno
- Condicionais (`if`, `elif` e `else`)
- Loops (`for`)
- Strings
- Listas
- Índices
- Manipulação de texto
- Métodos como `split()`, `join()`, `find()` e `count()`
- `enumerate()`
- Validação de entradas
- Tratamento de casos limite
- Organização de algoritmos
- Resolução de problemas

---

## 🎯 Objetivo

Mais do que concluir os desafios, o foco é compreender a lógica por trás de cada solução e desenvolver boas práticas de programação.

Cada laboratório representa um passo na construção de uma base sólida em Python, preparando o caminho para estudos mais avançados em desenvolvimento de software, automação, análise de dados e inteligência artificial.
