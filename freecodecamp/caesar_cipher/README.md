# Caesar Cipher

## 📖 Sobre o laboratório

Neste laboratório do freeCodeCamp, o objetivo foi implementar a Cifra de César, um dos algoritmos clássicos de criptografia.

A aplicação permite criptografar e descriptografar textos utilizando um deslocamento configurável, preservando letras maiúsculas e minúsculas.

---

## 🎯 Objetivos

- Criar funções em Python
- Trabalhar com parâmetros e valores padrão
- Validar entradas
- Manipular strings
- Utilizar `str.maketrans()` e `translate()`
- Implementar criptografia e descriptografia

---

## 🛠️ Conceitos praticados

- Funções
- Parâmetros
- Condicionais
- Strings
- Tradução de caracteres
- Validação de tipos
- Valores padrão em funções

---

## 💡 Minha solução

A solução cria uma função principal responsável por realizar a tradução dos caracteres e duas funções auxiliares para criptografar e descriptografar mensagens.

Também foi implementada validação para garantir que o deslocamento informado seja um número inteiro.

---

## ▶️ Exemplo

```python
encrypt("freeCodeCamp", 3)
```

Resultado:

```
iuhhFrghFdps
```
