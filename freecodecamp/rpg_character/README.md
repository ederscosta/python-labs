# RPG Character Builder

## 📖 Sobre o laboratório

Neste laboratório do freeCodeCamp, o objetivo foi desenvolver uma função capaz de criar um personagem para um jogo de RPG.

A função valida o nome do personagem, distribui os atributos e gera uma ficha formatada utilizando indicadores visuais.

---

## 🎯 Objetivos

- Criar funções
- Validar parâmetros
- Trabalhar com condicionais
- Utilizar operadores lógicos
- Construir strings formatadas

---

## 🛠️ Conceitos praticados

- Funções
- Strings
- Condicionais
- Operadores lógicos
- Validação de dados
- F-strings

---

## 💡 Minha solução

A solução valida todas as entradas antes de gerar a ficha do personagem.

Caso alguma regra seja violada, uma mensagem de erro é retornada. Caso contrário, a função monta uma ficha utilizando círculos preenchidos e vazios para representar os atributos.

---

## ▶️ Exemplo

```python
print(create_character('ren', 4, 2, 1))
```

Resultado:

```
ren
STR ●●●●○○○○○○
INT ●●○○○○○○○○
CHA ●○○○○○○○○○
```
